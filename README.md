# 45 Days of Python Programming

## Internship Overview

This repository contains my 45-day Python programming practice journey. During this internship, I learned Python fundamentals, data structures, object-oriented programming, file handling, database connectivity, data analysis, and practical project development.

The main objective was to improve my Python programming skills through daily coding exercises and practical implementations.

## Objectives

- Understand Python programming fundamentals.
- Learn functions, loops, and data structures.
- Understand object-oriented programming.
- Practice file handling and exception handling.
- Work with Python libraries and modules.
- Learn database connectivity.
- Understand APIs and web scraping.
- Practice data analysis and visualization.
- Develop practical Python projects.
- Learn Git and GitHub for version control.

## Topics Covered

### 1. Python Fundamentals
Variables, data types, operators, conditional statements, loops, strings, lists, tuples, sets, and dictionaries.

### 2. Functions and Modules
Functions, lambda functions, modules, arguments, decorators, and generators.

### 3. Object-Oriented Programming
Classes, objects, inheritance, polymorphism, encapsulation, and abstraction.

### 4. File Handling and Exception Handling
Reading, writing, appending files, CSV, JSON, and exception handling.

### 5. Advanced Python Concepts
Random module, datetime, regular expressions, OS module, and multithreading.

### 6. Database and Web Technologies
SQLite database connectivity, API requests, and web scraping.

### 7. Data Analysis and Visualization
NumPy, Pandas, Matplotlib, data analysis, and graph creation.

## Practical Projects

### Student Management System
A Python-based console application that allows users to:

### Online Examination System
A Python-based quiz application that allows users to:
